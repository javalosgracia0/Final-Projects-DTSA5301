# NYPD Shooting Incident Analysis

This project analyzes historical NYPD shooting incident data to identify patterns across seasons, boroughs, and years.

## Project Files
- R Markdown (.Rmd): Reproducible analysis and code
- HTML Report (.html): Completed analysis and visualizations
- Video Presentation (.mp4): Overview of findings

## How to Reproduce
1. Download the R Markdown file.
2. Open it in RStudio.
3. Install the required R packages.
4. Click Knit to reproduce the analysis.
5. Download the mp4 as well, it will not show a raw/preview
